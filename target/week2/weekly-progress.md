# Weekly Progress Report

## Week 2
### Project: Campus Placement and Internship Portal

## Focus
Database Design and Planning

---

## Work Completed

During Week 2, I worked on designing the database structure required
for the Campus Placement and Internship Portal.

### 1. Database Selection

MySQL was selected as the database management system for storing and
managing application data.

### 2. Entity Identification

The major entities required by the system were identified:

- Users
- Students
- Companies
- Jobs
- Applications

### 3. Table Design

The structure of the major database tables was planned.

The following information was identified for each table:

- Column names
- Data types
- Primary keys
- Foreign keys
- Required fields
- Unique fields
- Default values

### 4. Relationship Design

Relationships between the major entities were identified.

The planned relationships include:

- Users → Students
- Users → Companies
- Companies → Jobs
- Students → Applications
- Jobs → Applications

### 5. Data Integrity

Database constraints were planned to maintain data consistency.

These include:

- Primary keys
- Foreign keys
- Unique constraints
- NOT NULL constraints
- Referential integrity

### 6. Database Schema

An initial SQL database schema was prepared for the project.

The schema contains tables for:

- User accounts
- Student profiles
- Companies
- Job/internship opportunities
- Applications
